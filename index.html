Common metrics

MSE = (1/m) Σ (ŷ − y)² RMSE = √MSE R² = 1 − SS_res / SS_tot Accuracy = (TP+TN)/Total Precision = TP/(TP+FP) Recall = TP/(TP+FN) F1 = 2·P·R/(P+R)

Exp 1 – Linear Regression (1 variable)

California Housing: AveRooms → house price. Gradient descent vs normal equation.

Algorithm (gradient descent)

  1. Start with θ₀ = 0, θ₁ = 0.
  2. Predict ŷ = θ₀ + θ₁x.
  3. Find error = ŷ − y.
  4. Update θ₀ and θ₁ using the gradient.
  5. Repeat for 1000 epochs and note the cost each time.

Procedure

  1. Load dataset, pick AveRooms (X) and MedHouseVal (y).
  2. Remove outliers (rooms < 10, price < 5).
  3. Split 80/20, then StandardScaler.
  4. Run gradient descent (lr = 0.01) and plot the cost curve.
  5. Run normal equation.
  6. Calculate MSE, RMSE, R² for both.
  7. Plot data points with the fitted line.

Formulas

h(x) = θ₀ + θ₁x J = (1/2m) Σ (h(xᵢ) − yᵢ)² θ₀ := θ₀ − α(1/m) Σ (h − y) θ₁ := θ₁ − α(1/m) Σ (h − y)·x Normal eq: θ = (XᵀX)⁻¹ Xᵀ y
Both methods give almost the same θ, MSE and R² (≈ 0.2).

Exp 2 – Polynomial Regression

Auto MPG: displacement → mpg. Compare with linear.

Algorithm

  1. Choose degree d.
  2. Expand x into x, x², … , xᵈ.
  3. Fit ordinary linear regression on these new features.
  4. Predict and calculate MSE, R².
  5. Repeat for d = 1, 2, 3, 4, 6, 8 and compare.

Procedure

  1. Load mpg.csv, drop missing values.
  2. X = displacement, y = mpg; split 80/20.
  3. Train the linear baseline.
  4. Loop over degrees with PolynomialFeatures + LinearRegression.
  5. Make a table of MSE, RMSE, R² for each degree.
  6. Plot the curves for d = 2, 4, 8 with the linear line.

Formulas

h(x) = θ₀ + θ₁x + θ₂x² + … + θᵈxᵈ J = (1/2m) Σ (h(xᵢ) − yᵢ)²
d = 2–3 is best. d ≥ 8 overfits (test error rises). d = 1 underfits.

Exp 3 – Ridge & Lasso Regression

Diabetes dataset: compare with plain linear regression.

Algorithm

  1. Scale all features.
  2. Train plain linear regression (baseline).
  3. Try many α values (0.001 to 100) with 5-fold cross-validation.
  4. Pick the α with the lowest average validation error.
  5. Refit Ridge and Lasso with the best α.
  6. Compare MSE and R² on the test set.

Procedure

  1. Load diabetes data (10 features, target).
  2. Split 80/20 and apply StandardScaler.
  3. Fit LinearRegression.
  4. Use RidgeCV and LassoCV (cv = 5) to get best α.
  5. Refit Ridge and Lasso.
  6. Print results table and plot coefficients of all three.

Formulas

Ridge: J = (1/2m) Σ (h − y)² + α Σ θⱼ² (L2) Lasso: J = (1/2m) Σ (h − y)² + α Σ |θⱼ| (L1)
Ridge shrinks coefficients but keeps all. Lasso makes some exactly 0, so it does feature selection. Both are slightly better than plain linear.

Exp 6 – Logistic Regression: with vs without scaling

Pima Indians Diabetes dataset.

Algorithm

  1. Compute z = wᵀx + b, then p = sigmoid(z).
  2. If p ≥ 0.5 predict 1, else 0.
  3. Update w to reduce log-loss (solver: saga).
  4. Train once on raw data, once on standardized data.
  5. Compare the metrics.

Procedure

  1. Load CSV, give column names, X = features, y = Outcome.
  2. Split 70/30.
  3. Train LogisticRegression on unscaled data.
  4. Fit StandardScaler on train only, transform train and test.
  5. Train again on scaled data.
  6. Compute accuracy, precision, recall, F1 for both.
  7. Plot the coefficient bars.

Formulas

σ(z) = 1 / (1 + e⁻ᶻ), z = wᵀx + b Log-loss = −(1/m) Σ [ y·log(ŷ) + (1−y)·log(1−ŷ) ] Z-score: x_scaled = (x − mean) / std
Scaling gives faster, stable convergence. Accuracy ≈ 0.74–0.78 (scaled) vs 0.64–0.70 (unscaled).

Exp 8 – KNN on Fashion MNIST

Try K = 1, 3, 5, 11.

Algorithm

  1. Store all training images (lazy learner, no real training).
  2. For a test image, find the distance to every training image.
  3. Pick the K nearest.
  4. Majority vote gives the class.
  5. Repeat for each K value.

Procedure

  1. Load Fashion MNIST; take 5000 train and 500 test images.
  2. Flatten 28×28 to 784 features and divide by 255.
  3. For each K, build KNeighborsClassifier (euclidean).
  4. Note fit time and predict time.
  5. Calculate accuracy and macro F1.
  6. Plot accuracy and latency against K.

Formulas

Euclidean: d(x, q) = √ Σ (xᵢ − qᵢ)² Search cost per query = O(M × N) (M = training samples, N = features)
Small K: low bias, high variance (overfit). Large K: smooth, can underfit. Best around K = 3 or 5 (≈ 81–85%).

Exp 9 – Decision Tree (ID3)

Customer segmentation using Recency, Frequency, Monetary tiers.

Algorithm (ID3)

  1. Calculate entropy of the whole dataset.
  2. For each attribute, calculate information gain.
  3. Choose the attribute with the highest gain as the node.
  4. Split data by that attribute’s values.
  5. Repeat on each subset with remaining attributes.
  6. Stop when the subset is pure, attributes are over, or max depth is reached. Leaf = majority class.

Procedure

  1. Create the retail data (Recency, Frequency, Monetary tier, Segment).
  2. Convert text categories to numbers.
  3. Split 75/25.
  4. Train DecisionTreeClassifier(criterion = entropy, max_depth = 3).
  5. Find accuracy.
  6. Draw the tree with plot_tree.
  7. Plot feature_importances_.

Formulas

Entropy: H(S) = − Σ pᵢ log₂(pᵢ) Gain(S, A) = H(S) − Σ (|S_v| / |S|) · H(S_v)
Monetary tier is the most important feature (root), then Frequency, then Recency.

Exp 11 – Linear SVM

Iris: Setosa vs Non-Setosa.

Algorithm

  1. Find the line (hyperplane) that separates the two classes.
  2. Choose the one with the maximum margin.
  3. Points touching the margin are the support vectors.
  4. Soft margin: allow some mistakes, controlled by C.
  5. Classify a new point by the sign of wᵀx + b.

Procedure

  1. Load Iris, use petal length and petal width.
  2. Label: Setosa = 1, others = 0.
  3. Split 80/20 (stratified), apply StandardScaler.
  4. Train SVC(kernel = linear, C = 1).
  5. Calculate accuracy, precision, recall, F1, confusion matrix.
  6. Plot the boundary, the two margin lines and the support vectors.

Formulas

Hyperplane: wᵀx + b = 0 Constraint: yᵢ(wᵀxᵢ + b) ≥ 1 Margin = 2 / ||w|| Soft margin: minimize ½||w||² + C Σ ξᵢ Decision: f(x) = sign(wᵀx + b)
Small C: wide margin, more errors allowed. Large C: narrow margin, fits training data tightly. Result ≈ 100% accuracy.

Exp 12 – SVM Kernels (Linear, Poly, RBF)

Fashion MNIST, 10 classes.

Algorithm

  1. Reduce data size (subsample + PCA).
  2. Train an SVM with each kernel.
  3. Kernel computes similarity in a higher dimension without actually moving there (kernel trick).
  4. Multi-class is handled with one-vs-one / one-vs-rest.
  5. Compare accuracy and training time.

Procedure

  1. Load data, take a stratified 6000 images.
  2. Divide by 255, split 80/20, StandardScaler.
  3. PCA: 784 features to 50.
  4. Train SVC linear, poly (degree 3), rbf (C = 1).
  5. Note training time of each.
  6. Calculate accuracy, precision, recall, F1 (macro).
  7. Plot the confusion matrix of the best kernel.

Formulas

Decision: f(x) = sign( Σ αᵢ yᵢ K(xᵢ, x) + b ) Linear: K = xᵢᵀxⱼ Poly: K = (γ·xᵢᵀxⱼ + r)ᵈ RBF: K = exp(−γ ||xᵢ − xⱼ||²)
RBF is best (≈ 0.83–0.88). Linear is fastest. Shirt, T-shirt, Pullover and Coat get confused most.

Exp 14 – Activation Functions (MNIST)

Sigmoid vs Tanh vs ReLU in a neural network.

Algorithm

  1. Forward pass: each neuron = activation(Σ w·x + b).
  2. Find the loss (cross-entropy).
  3. Backpropagation: compute gradients with the chain rule.
  4. Update the weights.
  5. Repeat for each epoch with each activation and compare.

Procedure

  1. Load MNIST (fetch_openml), divide by 255.
  2. Split 85/15.
  3. For each of logistic, tanh, relu: build MLPClassifier(hidden = (128, 64), max_iter = 25).
  4. Train and save loss_curve_ and test accuracy.
  5. Plot the loss curves together and compare.

Formulas

Sigmoid: f(x) = 1/(1+e⁻ˣ) f′ = f(1 − f) Tanh: f(x) = (eˣ − e⁻ˣ)/(eˣ + e⁻ˣ) f′ = 1 − f² ReLU: f(x) = max(0, x) f′ = 1 if x > 0 else 0
Sigmoid’s max derivative is 0.25, so gradients vanish in deep layers. Order: ReLU (96–98%, fastest) > Tanh (93–95%) > Sigmoid (88–92%, slowest).

Exp 16 – K-Means vs Hierarchical Clustering

Mall Customer: Annual Income and Spending Score.

Algorithm: K-Means

  1. Choose K and place the initial centroids (k-means++).
  2. Assign each point to its nearest centroid.
  3. Move each centroid to the mean of its points.
  4. Repeat steps 2–3 until nothing changes.

Algorithm: Agglomerative

  1. Start with every point as its own cluster.
  2. Merge the two closest clusters (Ward linkage).
  3. Repeat until one cluster remains, then cut the dendrogram at K.

Procedure

  1. Load data, pick Income and Spending Score.
  2. Apply StandardScaler.
  3. Elbow method: run K-Means for K = 2 to 10 and plot WCSS.
  4. Fit K-Means with K = 5.
  5. Fit AgglomerativeClustering (n = 5, ward).
  6. Calculate silhouette score for both.
  7. Plot the clusters and the dendrogram.

Formulas

WCSS = Σₖ Σ_{x∈Cₖ} ||x − μₖ||² Silhouette: s = (b − a) / max(a, b) a = avg distance within own cluster b = avg distance to nearest other cluster Ward: ΔESS = (|A||B| / (|A|+|B|)) · ||μ_A − μ_B||²
K-Means silhouette ≈ 0.55–0.58, Agglomerative ≈ 0.53–0.56. Silhouette near +1 means good clusters.
